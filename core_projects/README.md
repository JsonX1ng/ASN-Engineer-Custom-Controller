Please create a new directory for major projects only, e.g. infantry, hero, engineer_controller, vibration_test_stand, etc. Use the Misc. Development folder for smaller T+D projects.


When creating a new project, please create a new branch OFF OF DEV for the project, called "[insert_board_name]-[insert_project_name]". This branch will stay permenently parallel to main, only being merged into main when a stable version is achieved

Please make sure to pull updated libraries from dev frequently
